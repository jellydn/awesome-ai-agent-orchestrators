# Contributing

Thanks for helping improve Awesome AI Agent Orchestrators.

## What belongs here

A project should do at least one of the following:

- Run or supervise multiple coding-agent sessions.
- Isolate agent work with Git worktrees, clones, containers, VMs, or sandboxes.
- Coordinate tasks or communication between coding agents.
- Provide a review/merge workflow specifically useful for agent-authored code.
- Provide a companion capability that materially improves an orchestrated coding-agent workflow.

Generic AI chat apps, model wrappers, prompt collections, and unrelated automation tools are out of scope.

## Adding a project

1. Add the project to the narrowest relevant section.
2. Link to the canonical upstream repository.
3. Keep the description factual and to one sentence.
4. Mention important limitations such as source-available or discontinued status when relevant.
5. Keep entries alphabetically ordered within a section when practical.

Use this format:

```markdown
- [owner/project](https://github.com/owner/project) - Short factual description.
```

Please verify that the link works before opening a pull request.
